**RULES FOR PULLING/UPLOADING CAD/FILES**
- **Always pull before you start** your own work so you have the most updated CAD
- **Always push after each CAD session**, even if it's not fully done
  - There should be **no errors** in both parts and assemblies; if there are I will slime you out
- Do not edit someone else's CAD unless needed
  - If you do, please make sure to communicate with that person first
- Follow the folder and naming convention below

**FOLDERS**
- Title Case
  - For example, "This is a Payload"
- Please put your CAD in your respective folders
  - NASA USLI
  - Spaceshot
  - Other Payloads
    - All CAD that is not related to a NASA USLI or Spaceshot payload

**CAD**
- ALL UPPERCASE
- PL[YEAR]-[CATEGORY]-[RELEVANT-NAME]-[PART-NUMBER-(IF-NECESSARY)]
  - Categories
    - NASA USLI Proposal: PRO
    - NASA USLI Prototyping: PT
    - NASA USLI Fullscale: FS
    - Spaceshot: SS
    - Others: Any 2-3 letter abbreviation that is different from the ones above, relevant to your payload, and consistent amongst all related **parts/assemblies**
      - For example: Coffee Payload - COF
  - Part Number (PN) Cclause: If you have downloadable CAD, copy the PN at the end
    - Example: PL27-FS-M3-10MM-SCREW-91290A115
  - General Examples
    - PL27-PRO-BUSHING
    - PL27-FS-PUSH-PLATE-GUIDE
    - PL27-SS-AIRFRAME
    - PL27-COF-GROUNDS-CHAMBER
    - PL27-PT-LINKAGE-1
    - PL27-FS-4-40-0.5IN-SHEAR-PIN-95868A260
